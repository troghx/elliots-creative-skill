# Jiro Components Visual Audit

Source reviewed: <https://jiro.build/components>  
Audit date: 2026-07-14

## Scope and Ethics

This audit studied the public catalog, accessible labels, public thumbnails, tab behavior, category inventory, and representative previews. Premium source code was not accessed or extracted. Public previews may be used either as inspiration or, when the user explicitly asks, as visual targets for a close rebuild using independent code. Never bypass premium access or reuse assets the user does not own or provide.

## Broad Visual Findings

A representative visual scan covered 48 public thumbnails across popular heroes, section types, buttons, backgrounds, and cards, plus the text inventory of the larger catalog.

### Heroes

1. **Scene first:** imagery often fills the canvas; type occupies natural negative space instead of sitting inside a generic panel.
2. **One dominant object:** a product, animal, building, hand, or abstract form owns the scene.
3. **Message split across space:** headlines sometimes occupy opposite corners or interact with the subject.
4. **Oversized type:** a single word can become environmental rather than merely textual.
5. **Quiet navigation:** headers usually recede so the scene and claim remain dominant.
6. **Controlled UI fragments:** floating interface pieces appear when they explain a platform, not as decoration alone.
7. **Material specificity:** wood, water, glass, metal, foliage, packaging, and atmospheric light make otherwise minimal layouts memorable.

### Sections

1. **Editorial rows beat card grids:** awards, metrics, about, and FAQs frequently rely on type and alignment.
2. **Process sections use visible sequence:** large numerals, paths, or staged objects make order obvious.
3. **Testimonials vary by proof strategy:** one strong quote, landscape strip, masonry archive, bento field, or video portrait.
4. **Pricing uses contrast hierarchy:** one plan or decision path dominates; surrounding options stay quieter.
5. **Integration sections organize logos around a center or baseline:** the best versions communicate flow or breadth without independent logo animation.
6. **CTAs often become a scene:** a product fan, document stack, object, or environmental image carries the close instead of another colored box.
7. **Footers can finish the composition:** they may share the page background and act as the final chapter.

### Buttons

Public examples exposed names and thumbnails for Spot Fill, Circle Reveal, Jelly Explore, Swap, Glow, Neon Typing, Electric Border, Left-to-Right Scan, Light Beam, Chrome Bezel 3D, Metal, Liquid Glass, and Glow Color.

Transferable lesson: a button should have one material or state-change idea. Do not combine elastic scale, scan line, glow, label swap, and magnetic movement on the same control.

### Backgrounds

Representative public items included Energy Beam, Aurora Gradient, and Fluid Gradient Engine. The catalog count indicates many more variations, but the useful families reduce to directional light, low-frequency color fields, particles/energy, texture, depth, and environmental motion.

Transferable lesson: choose a background based on narrative function. Aurora and fluid gradients are not automatic shorthand for “AI.”

### Cards

The public card category showed Swiss-style and Stacked Card patterns.

Transferable lesson: cards can be either flat information grids or physical sequential objects. A card should not exist merely because a container is easy to draw.

## What Not to Extract or Reuse

- component code behind premium access
- exact asset choices or generated subjects
- brand names, copy, wordmarks, or proprietary illustrations
- screenshots as production assets

Visible layout, typography treatment, color relationships, spacing, motion, and composition may be reproduced closely when the user requests reference fidelity. Adapt brand copy, logos, imagery, content, and technical implementation unless the user owns or supplies them.

## Original Synthesis Method

Use this method only when the request is for an original direction rather than a faithful visual rebuild.

1. Pick one business truth.
2. Choose one visual metaphor tied to that truth.
3. Select one hero family and one supporting section rhythm.
4. Borrow no more than one interaction principle from any single reference.
5. Change subject, layout proportions, type logic, crop, palette role, and motion trigger.
6. Verify the result still makes sense without naming the reference.

If a reviewer can immediately identify the exact Jiro component being imitated, the synthesis is not original enough.
