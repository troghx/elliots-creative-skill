# Three directions

A direction is a decision about how the product behaves and feels, not a color swatch. Three real directions give the user a choice; three variations of one layout give them none.

## The axes

Every direction takes a position on each axis. Two directions must differ on at least three.

| Axis | One end | Other end |
| --- | --- | --- |
| Structure | single column, linear story | spatial canvas, many panes |
| Density | roomy, one thing at a time | dense, everything comparable |
| Type voice | neutral grotesk, quiet | condensed display, serif accents, loud |
| Color & material | monochrome, flat, paper | saturated, layered, glass, metal, light |
| Motion personality | still, instant | physical, playful, narrative |
| Signature moment | none, pure utility | one memorable interaction or image |
| Imagery | none or data only | illustration, photography, 3D, objects |

## The spread

1. **Refine:** the current product or brief, done well. Keeps recognition and fixes the friction. The safest, never the laziest.
2. **Commit:** one idea pushed until it shapes layout, type and motion together.
3. **Wildcard:** borrowed from somewhere the user would not expect, yet defensible against the brief.

Add a fourth only when the brief is genuinely ambiguous (for example, unsure whether the audience is buyers or users).

## Archetypes to start from, not to finish with

- **Calm instrument:** BoardUI-grade precision, semantic color only for state, keyboard first. For tools and dashboards.
- **Data as hero:** the main number or chart is the page; everything else supports it.
- **Editorial:** strong typographic hierarchy, generous measure, images cropped with intent.
- **Authored playground:** a personal visual language with objects, inline icons and physical motion ([Kenji notes](kenji-lambert.md)). For portfolios, campaigns and brand landings.
- **Product diorama:** one object or interface staged as a scene ([composition](creative-composition.md)).
- **Soft tactile:** rounded, cushioned controls, springy feedback, warm neutrals.
- **Signal / brutalist utility:** raw grid, mono type, high contrast, honest controls.
- **Narrative scroll:** the page as a sequence of states that tells the offer's story.

## Wildcard generators

Use one when the first two ideas feel familiar.

- An object from the domain: ticket, receipt, lab report, departure board, recipe card, cassette, trading card.
- A craft: risograph print, signage, packaging, bookbinding, broadcast graphics.
- A place or era: airport, arcade, newsroom, 70s Swiss poster, early web.
- A physical behavior: hanging, stacking, peeling, magnetism, pouring.

Keep only what serves the user's one action. A wildcard that slows the frequent task is decoration.

## Presenting

For each direction:

```text
### <Name>
Idea: <one sentence>
Composition: <layout in a line or a small ASCII sketch>
Type · color · material: <choices>
Signature moment: <the one thing people remember>
BoardUI: <components, marked free or PRO; "reference only" if the stack does not fit>
Trade-off: <what it costs or risks>
```

End with a recommendation and its reason in one or two sentences. Keep the whole proposal scannable; the user is choosing, not reading an essay.

## After the choice

Lock the decision before writing UI: tokens (color roles, type scale, radii, spacing, motion durations), the component list (installed versus custom) and the signature moment's behavior, including its reduced-motion version. Then build. If the chosen direction stops fitting halfway through, say so and propose the adjustment instead of drifting.
