# Creative Composition Library

Use this reference as a set of compositional grammars. Combine a small number of compatible patterns around one concept spine. When the user asks for an original direction, synthesize rather than trace. When the user supplies a visual target and asks for fidelity, reproduce the visible result closely with independent code and adapted content; never extract gated source or unprovided proprietary assets.

## Selection Rule

Choose:

- one hero grammar
- one navigation grammar
- one content rhythm
- one CTA grammar
- one motion grammar

Add a second visual device only when it supports the same metaphor.

## Hero Grammars

### 1. Cinematic Environment

**Structure:** full-bleed scene, quiet navigation, copy positioned in natural negative space, CTA anchored to the visual path or subject gaze.

**Best for:** emotional services, real estate, hospitality, food, travel, mission-driven brands.

**Make it original:** choose a scene that encodes the offer, not a generic beautiful landscape. Let weather, light, distance, or terrain represent the user's progress.

**Risk:** poor crop can bury the message. Protect text with local contrast rather than darkening the whole image.

### 2. Product Diorama

**Structure:** one oversized object centered or offset in a controlled studio scene; microcopy and controls orbit it.

**Best for:** physical products, packaged goods, mobility, hardware, consumer tech.

**Motion:** slow rotation, light sweep, exploded layers, or ingredient orbit.

**Risk:** becomes a generic 3D render if the object has no story or material specificity.

### 3. Editorial Split Tension

**Structure:** message divided across left/right or top/bottom poles; image or object bridges the gap.

**Best for:** finance, agencies, portfolios, transformation narratives.

**Motion:** the two poles converge, trade places, or reveal a third meaning.

**Risk:** reading order can become ambiguous on mobile. Collapse into one decisive stack.

### 4. Oversized Word as Landscape

**Structure:** a brand word or outcome becomes the largest visual object; photography or product intersects the letterforms.

**Best for:** bold retail, food, culture, editorial, launch pages.

**Motion:** mask reveal, letter tracking, crop travel, object passes through glyph layers.

**Risk:** the word must remain readable and must not duplicate a weaker heading below it.

### 5. Spatial UI Constellation

**Structure:** real interface fragments float around one central promise or object, using depth and scale to explain an ecosystem.

**Best for:** platforms, integrations, automation, data products.

**Motion:** pieces converge into a workflow, then settle.

**Risk:** floating rectangles quickly become SaaS wallpaper. Use actual states and a meaningful sequence.

### 6. Quiet Monument

**Structure:** extreme whitespace, one precise object or image, short type, subtle material detail.

**Best for:** luxury, premium services, architecture, design studios.

**Motion:** nearly still; one soft lighting or perspective change.

**Risk:** requires excellent copy, imagery, and spacing. Empty is not automatically premium.

### 7. Window or Portal

**Structure:** content is seen through a frame, mask, lens, device, door, tunnel, or aperture.

**Best for:** discovery, transformation, before/after, travel, creative tools.

**Motion:** aperture opens, focus shifts, or the camera moves through the threshold.

**Risk:** do not trap core content inside a decorative mask on small screens.

### 8. Human/Object Hand-off

**Structure:** two hands, agents, tools, or states reach toward one another around the headline.

**Best for:** collaboration, human-plus-AI, marketplaces, service handoffs.

**Motion:** connection completes only after the primary message is readable.

**Risk:** avoid cliché “Creation of Adam” imitation; use a brand-specific exchange.

## Navigation Grammars

### Invisible Edge Navigation

Minimal wordmark and two or three controls placed at scene edges. Works with strong environmental heroes. Maintain visible focus states and a solid fallback over changing backgrounds.

### Dynamic Island

A compact floating capsule containing the current section, primary action, or buyer-mode switch. Use when the island changes state with scroll; otherwise a normal header is simpler.

### Editorial Index

Numbered sections or short text links form a visible table of contents. Good for portfolios and long-form stories.

### Dual-Pole Navigation

Brand and utility sit on opposite edges with the center intentionally empty. Good when the hero object owns the center.

### Command Strip

A functional, product-like bar with search, mode, or action controls. Good for tools and data products; poor fit for emotional consumer services.

## Content Rhythms by Section

### About

- **Manifesto spread:** one oversized sentence plus a compact proof column.
- **Image ledger:** vertical image sequence paired with dates, facts, or milestones.
- **Before/after field:** two states share one continuous scene instead of two boxed cards.
- **Founder annotation:** portrait or artifact with marginal notes rather than a biography card.

### Features

- **Object orbit:** features live around one product or mechanism.
- **Sequential canvas:** one stage changes as the user scrolls through capabilities.
- **Editorial rows:** large numbered statements with one proof detail each.
- **Real UI reveal:** expose the actual interface in progressive layers.
- **Specimen shelf:** physical variants arranged like a collection, useful for products and produce.

Avoid defaulting to three equal icon cards. Use cards only when each item truly behaves as an independent object.

### How It Works

- **Single path:** steps sit on one directional line, road, timeline, conveyor, or river.
- **State machine:** one object visibly changes at each step.
- **Three-act spread:** problem, mechanism, result with a clear visual transformation.
- **Sticky demonstration:** explanation scrolls while one visual stays and updates.

### Brands and Integrations

- **Constellation:** integrations connect to a central system.
- **Data rail:** logos move on a restrained track with real categories.
- **Proof field:** logos share space with one metric or outcome.
- **Workflow wiring:** lines show actual data flow rather than decorative spaghetti.

Do not animate every logo independently.

### Why Choose Us

- **Evidence ledger:** claim on the left, proof and source on the right.
- **Constraint comparison:** show what the product deliberately does and does not do.
- **Outcome staircase:** metrics increase with a clear baseline and context.
- **Material demonstration:** use process photography, samples, or real artifacts.

### Testimonials

- **Editorial quote:** one quote at a time with strong typography and a controlled crossfade.
- **Landscape strip:** testimonials share one environmental image and horizontal rhythm.
- **Masonry archive:** useful only when volume itself is proof.
- **Video portrait:** one human story supported by transcript and captions.
- **Result annotation:** quote paired with measurable before/after context.

Never create auto-scrolling text that cannot be paused.

### Stats and Metrics

- **Rising scale:** bars, type, or objects build in sequence.
- **Metric horizon:** values align to a common baseline like a skyline.
- **One hero number:** one metric owns the section; secondary values stay quiet.
- **Operational strip:** metrics attach directly to workflow steps.

Always label timeframe, sample, or unit when it matters.

### Team

- **Casting wall:** consistent portraits with role and one human detail.
- **Editorial roster:** text-first list with portraits revealed on hover/focus.
- **Working scene:** candid process image with annotated roles.
- **Spotlight sequence:** one person at a time, good for small teams.

### Pricing

- **Decision table:** compare only the variables that change a decision.
- **Progressive commitment:** plans mapped to readiness or scale.
- **One recommended route:** a dominant plan plus quieter alternatives.
- **Estimator:** useful when price depends on a real variable.

Do not use fake scarcity or conceal terms.

### FAQ

- **Split context:** questions on one side, a relevant object, image, or support route on the other.
- **Editorial index:** categories first, then concise answers.
- **Searchable help:** for large sets, provide filtering rather than endless accordions.
- **Objection sequence:** order questions by conversion friction, not internal organization.

### Contact

- **Direct handoff:** one clear human or team destination plus expected response time.
- **Mode chooser:** sales, support, partnership, or wholesale paths.
- **Conversational form:** one question at a time when completion burden is high.
- **Compact brief:** one screen with only fields required for routing.

### Blog and Articles

- **Lead story:** one dominant article plus a quiet index.
- **Magazine rail:** strong crops, issue/date hierarchy, minimal card chrome.
- **Topic map:** categories behave like a content landscape.

### Footer

- **Integrated horizon:** footer content sits directly in the closing scene.
- **Index footer:** large navigation and contact details become the final composition.
- **Signature object:** one visual or wordmark closes the story.
- **Utility strip:** quiet legal and support links after the emotional close.

Avoid inserting a boxed footer surface when the page background can carry it legibly.

## CTA Grammars

### Plain Decisive Button

High-contrast label, generous hit area, minimal motion. Often the best choice when the hero already carries the spectacle.

### Spot Fill

A small color spot expands to fill the button on hover/focus. Good for clean editorial layouts.

### Circle Reveal

A circular mask reveals the active color or secondary label. Use with short labels and maintain contrast at every frame.

### Label Swap

Primary label slides out while a result-oriented label or arrow enters. Keep both accessible through one stable name.

### Jelly or Elastic

A small scale/shape response on press, not a constant wobble. Good for approachable consumer products; wrong for solemn legal or financial actions.

### Light Beam or Scan

A restrained specular sweep indicates focus or readiness. Good for dark technical interfaces; avoid migraine-like repetition.

### Electric Border

A brief traveling edge on hover/focus. Use sparingly as the sole neon device.

### Liquid Glass

Subtle refraction, border highlight, and depth over a rich scene. Ensure the background does not destroy label contrast.

### Metal or Material Button

Material response matches the product world: brushed metal, paper, rubber, glass, or fabric. Use real light logic, not texture noise.

## Background Systems

### Narrative Weather

Cloud, fog, rain, sunlight, or wind changes from one emotional state to another. Best when the product is about progress, clarity, relief, or resilience.

### Aurora Field

Large slow color masses with low-frequency movement. Good for calm technology and ambient depth; avoid using it as generic AI branding.

### Fluid Gradient

Color fields react to scroll or pointer movement. Keep movement slow and texture clean; provide a static gradient fallback.

### Energy Beam

One directional light or data beam organizes attention. Useful for connection, analysis, or transformation.

### Environmental Loop

Water, leaves, steam, dust, fabric, or light moves subtly inside a still scene. More believable than making the whole camera drift.

### Typographic Field

Oversized letters form the background and respond to scroll or crop. Good for bold brands with a meaningful word.

## Card Systems

### Swiss Editorial Card

Flat surface, typographic grid, strong alignment, almost no decoration. Best for facts, metrics, and serious content.

### Stacked Deck

Several items occupy one physical stack and advance through drag, click, or scroll. Best when sequence matters; do not hide critical information in the stack.

### Spatial Glass Card

A translucent plane floats over a scene. Use only where background context should remain visible. One or two planes are enough.

### Image Crop Card

The crop and caption hierarchy do the work; borders and shadows stay minimal.

### Metric Strip

A horizontal row of values shares a baseline and reads as one instrument, not many separate cards.

## Combination Recipes

### Calm Premium Service

Cinematic Environment + Invisible Edge Navigation + Editorial Quote + Integrated Horizon + Plain Decisive Button.

### Bold Consumer Product

Oversized Word + Product Diorama + Specimen Shelf + Label Swap Button + Editorial Index Footer.

### Technical Platform

Spatial UI Constellation + Command Strip + Sticky Demonstration + Workflow Wiring + Light Beam Button.

### High-Trust Financial Service

Narrative Weather or Quiet Monument + Evidence Ledger + Single Path + Editorial Quote + Plain Decisive Button. Keep language factual and motion calm.

### Creative Portfolio

Editorial Split Tension + Editorial Index + Lead Story + Text-first Roster + Signature Object Footer.

## Anti-Generic Checklist

- No three identical feature cards unless the content is genuinely parallel.
- No gradient blobs merely to fill empty space.
- No floating dashboard windows without a workflow.
- No six unrelated border radii.
- No every-section-on-a-card composition.
- No permanent cursor follower unless it performs a real action.
- No marquee as a substitute for hierarchy.
- No 3D object unrelated to the product.
- No “premium” achieved only through black backgrounds and glow.
- No image overlay so dark that the image stops contributing.
